# Mecha Survivor — POC

A single-level, Vampire-Survivors-style proof of concept built with
[Phaser 3](https://phaser.io). Setting: apocalyptic future, you pilot a
wanzer-style mecha (open-top cockpit, pilot visible) fighting off waves of
wasteland mutants and scavengers before a rogue military robot shows up to
end the level.

Everything you see is placeholder art — flat-colored, clean-silhouette PNGs
generated by a script, structured specifically so they're easy to swap for
real (e.g. AI-generated) sprites later. See `assets/README.md`.

## Run it

Browsers block loading local image files over `file://`, so serve the
folder instead of double-clicking `index.html`.

**Windows:** double-click `play.bat` in this folder. It starts a local
server (using Python or Node, whichever it finds) and opens the game in
your browser automatically. Close the extra "Mecha Survivor Server" window
when you're done playing.

**Mac/Linux, or manually:**

```bash
cd mecha-survivor-poc
python3 -m http.server 8080
# or: npx serve .
```

Then open `http://localhost:8080`.

## Controls

- **WASD** or **Arrow keys** — move
- Weapon **auto-fires at the nearest enemy** in range — no aiming needed
- Walk over **chests** and **XP gems** to pick them up
- On level-up, click a card or press **1 / 2 / 3** to choose an upgrade

## The loop

- **5 timed waves** of mutant crawlers (fast, weak, melee swarm) and
  scavengers (tougher, ranged, kite you), escalating in spawn rate each
  wave, then a **rogue robot boss** (wave 6) — melee slam (telegraphed
  red ring) + ranged bursts. Defeating it wins the level ("extraction
  successful"); dying at any point ends the run ("system down"). Both
  screens show wave/level/kills/time and a restart button.
- **XP orbs** drop from kills and get pulled in (magnet) once you're in
  pickup range; leveling up pauses the game and offers a **choice of 3
  random upgrades** (damage, fire rate, max HP, move speed, multishot,
  pickup radius, regen, range).
- **Chests** spawn periodically in the world, separately from leveling —
  walking over one instantly grants a random effect: heal, temporary
  damage/speed buffs, a shield, or an EMP that damages every enemy on
  screen. These are meant to feel like bigger, less predictable power
  spikes than the level-up picks.

## Project structure

```
index.html                  Phaser config + script includes (no bundler)
vendor/phaser.min.js         Phaser 3.80, vendored locally (MIT, see PHASER_LICENSE.md)
src/config/balance.js        All tunable numbers: stats, wave schedule, upgrade/chest pools
src/entities/Player.js       Movement, auto-targeting weapon, HP/XP/leveling, buffs
src/entities/Enemy.js        Shared enemy wrapper — crawler chase, scavenger kite+ranged, boss slam+ranged
src/systems/WaveManager.js   Timed wave spawner + boss-wave handoff, chest spawner
src/systems/UpgradeSystem.js Random upgrade/chest-pickup selection
src/scenes/BootScene.js      Asset preload
src/scenes/GameScene.js      World, camera, HUD, collisions, level-up/game-over/victory overlays
assets/sprites/               Placeholder PNGs (see assets/README.md)
assets/gen/make_sprites.py    Script that generated them (Pillow)
```

No build step or `npm install` needed to play — plain `<script>` tags in
dependency order. All balance numbers live in `src/config/balance.js` if you
want to retune difficulty, upgrade effects, or the wave schedule.

## Known limitations (it's a POC)

- Single static frame per sprite — no walk/attack animation yet.
- One level, no persistence between runs (by design, for this scope).
- No audio.
- Keyboard-only (no gamepad/touch controls).
- Arena is a large bounded plane with a camera that follows the player;
  there's no minimap.
